# Memories Rescue (working name)

Software Requirements Specification for a local Windows and macOS app that repairs your own Snapchat "Download My Data" Memories export: restores capture dates and GPS, merges caption overlays, and outputs a clean date-sorted library. Everything runs on your computer; no Snapchat login.
